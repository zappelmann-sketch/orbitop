# orbitop 0.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Parked items after 0.3.0 fixed, `system.py` split, release 0.4.0 prepared up to the user's run of `release.sh`.

**Architecture:** No new feature. Five small, independent tasks (split, footer, hardening, docs, matrix) and one release-prep task. Behaviour changes only where the spec names one (B1–B3, C2, E1).

**Tech Stack:** Python ≥ 3.12 (stdlib + PyGObject), ES modules in `orbitop/ui/js`, bash for `scripts/matrix`, pytest, headless Chrome check page (`tests/ui/check.html`).

**Spec:** `docs/superpowers/specs/2026-11-25-orbitop-0.4.0-design.md`

## Global Constraints

- No personal data in code, tests, docs, images or commit messages; neutral placeholders (`alice`, `user`, `/home/u`). Git identity: `zappelmann-sketch <235797375+zappelmann-sketch@users.noreply.github.com>`.
- Every source file starts with `SPDX-License-Identifier: GPL-3.0-or-later` and `Copyright © 2026 zappelmann-sketch`.
- Visible texts only through `orbitop/locale/en.json` and `de.json`, always both; system data never as HTML.
- `root` principle: readers take `root` and read `/proc`, `/sys` below it; tests use `tests/fixtures/roots/`.
- Tests never reach the real `/usr/bin/pkexec` (autouse guard in `tests/conftest.py`), never kill a real process, never touch the user's running orbitop or `~/.config/orbitop`.
- Files about 300 lines at most, one job per file. `procs.py` (300) and `sampler.py` (293) get no new lines beyond import changes.
- README.md and README.de.md keep the same structure (`tests/test_readme.py`).
- Strict suite green after each task: `pytest -q -W error::ResourceWarning -W error::DeprecationWarning`; `shellcheck` clean for changed shell files.
- No change to `counterhelper.py`, `killhelper.py`, polkit, udev or package scripts.

## Review Focus

1. Page reload after a finished PackageKit run (B2): no "Install" button, the distribution command is shown at once; a reload *before* any run still shows the button.
2. Switch on but not effective (B1): the `_again` text appears only for marker on + part `missing`; usable `no` still shows the README text; marker off shows the normal text.
3. Footer hides while it holds focus (B3): focus lands on "Über", never `body`, also when the last hint is hidden by a tick, not by a click.
4. A cancelled PackageKit run (C2): no D-Bus call after cancel, also between `CreateTransaction` and the first method on the transaction.
5. Matrix wrapper change (E2): `--` must not break any existing case; the full matrix with a throwaway key passes (controller step after Task 5).
