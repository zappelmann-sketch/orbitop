orbitop package source

This site is the signed package source of orbitop, a system monitor for Linux. It serves the packages for Debian and Ubuntu (apt), Fedora and openSUSE (RPM) and Arch Linux (pacman), so that updates arrive with the regular system update.

Fingerprint of the signing key orbitop-archive-keyring.asc:
B6F1 0E7E 76A6 3D9D 569D E067 4B5D 133F 7144 5C01

Compare it with the fingerprint in the README before you trust the key. The README explains how to install, update and remove orbitop.
